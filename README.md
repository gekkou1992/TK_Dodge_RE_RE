# TK Dodge RE RE

A modified version of [TK Dodge RE](https://github.com/max-su-2019/TK_Dodge_RE) by max-su-2019.

This project extends the original TK Dodge RE with additional dodge controls, animation features, and an in-game configuration menu.

## Changes and Features

### Dodge Controls

- **Sprint Key Double Tap**
  - Dodge by double-tapping the sprint key.
  - Configurable double-tap detection duration.
  - Supports dodging while sprinting.

- **Independent Dodge Hotkey**
  - Supports a dedicated dodge key alongside sprint-key dodging.
  - Dodge key can be reassigned through the in-game menu.

### Directional Dodge

- Added an option to prioritize horizontal or vertical dodge directions when moving diagonally.
- **8-Directional Dodge** is available as an optional download on Nexus Mods and requires compatible animations.

- **Legacy Dodge Method**
  - Added an option to switch between the original dodge behavior and the legacy dodge method.

### Dodge Footstep Sounds

- Added support for footstep and landing effects triggered by animation annotations.
- Supports custom animation events:
  - `TKDDodgeJumpUp`
  - `TKDDodgeJumpDown`
  - `TKDDodgeStepR`
  - `TKDDodgeStepL`
- Footstep effects can be enabled or disabled in the settings.

### SKSE Menu Framework Support

- Added an in-game configuration menu using SKSE Menu Framework.
- Supports changing dodge settings without manually editing INI files.
- Supports keyboard and gamepad button capture for dodge hotkey assignment.
- Right-click a setting to restore its default value.
- Menu changes are saved automatically to `Custom.ini`.

### Configuration

Settings are loaded in the following order:

1. `Data/SKSE/Plugins/TK Dodge RE.ini` — Original TK Dodge RE settings.
2. `Data/SKSE/Plugins/TK Dodge RE RE/TK Dodge RE RE.ini` — Additional settings.
3. `Data/SKSE/Plugins/TK Dodge RE RE/Custom.ini` — User settings generated by the in-game menu.

Later configuration files override earlier settings.

## Requirements

- Skyrim Script Extender (SKSE)
- Address Library for SKSE Plugins
- SKSE Menu Framework (for the in-game configuration menu)
- Original TK Dodge RE requirements, where applicable
